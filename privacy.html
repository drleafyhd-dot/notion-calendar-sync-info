이희동이 운영하는 Notion Calendar Sync는 운영자 본인만 사용하는 도구입니다. 이 문서는 현재 시험 운영의 데이터 처리와 향후 무인 운영 계획을 구분하여 설명합니다.

1. 처리하는 정보와 목적

  • Notion: 작업 식별자, 제목, 날짜, 분류, 완료·보관 상태 및 항목 링크 등 동기화 판단에 필요한 정보.
  • Google 및 iCloud: 계정·캘린더 식별 정보, 캘린더 목록, 동기화 일정의 제목·날짜·설명·식별자·변경 상태.
  • 연결 정보: OAuth 토큰, 앱 암호 등 API 인증에 필요한 자격 증명.
  • 운영 정보: 원본 항목과 일정 간 매핑, 변경 지문, 처리 상태와 오류 분류. 중복 생성 방지와 충돌 검토·복구에 사용합니다.

2. 사용과 전달

선택한 Notion 항목의 일정 정보는 운영자가 승인한 Google 및 iCloud 캘린더로 전달됩니다. 각 서비스는 자체 정책에 따라 데이터를 처리합니다. 이 도구는 사용자 데이터를 판매하거나 광고 목적으로 이용하지 않으며, 범용 AI 모델 학습에 사용하지 않습니다.

Google API에서 받은 정보의 사용 및 다른 앱으로의 전달은 Google API 서비스 사용자 데이터 정책의 Limited Use 요건을 따릅니다.

3. 저장과 보호

현재 시험 운영에서는 자격 증명을 암호화한 로컬 저장소와 일정 매핑 데이터베이스를 사용합니다. 자격 증명은 웹 안내 페이지에 포함하지 않습니다. NAS 보관과 무인 운영은 아직 적용되지 않았으며, 적용 전에 저장 권한·암호화·복구 절차를 확인합니다.

이 안내 사이트에는 로그인·입력 폼·광고·분석 스크립트·추적 쿠키를 넣지 않았습니다. 이 안내 사이트는 GitHub Pages를 사용합니다. GitHub는 보안을 위해 방문자의 IP 주소를 기록·보관합니다. 자세한 사항은 GitHub 개인정보처리방침을 확인하세요. 이는 동기화 자격 증명이나 일정 데이터를 GitHub에 저장한다는 뜻이 아닙니다.

4. 보관 및 삭제

매핑과 처리 상태는 동기화가 유지되는 동안 중복 방지와 복구에 사용합니다. 자격 증명은 연결 유지에 필요한 동안 보관하며, 연결 종료 시 운영자가 폐기합니다. 운영 종료 시 더 이상 필요하지 않은 로컬 데이터와 백업도 확인 후 삭제합니다. 현재 자동 보존 기한이나 자동 삭제 작업은 설정되어 있지 않습니다.

원본 항목의 완료·보관·날짜 제거 또는 조회 누락만으로 캘린더 일정을 자동 삭제하지 않습니다. 연결 해제 또한 Google·iCloud에 이미 생성된 일정을 자동 삭제하지 않으며, 필요한 삭제는 해당 캘린더에서 별도로 수행합니다.

5. 연결 해제와 문의

Google 계정의 연결된 앱 관리에서 접근 권한을 철회할 수 있습니다. Apple 계정에서는 앱 암호를 폐기하고, Notion에서는 연결의 접근 권한을 제거할 수 있습니다. 이후 로컬 자격 증명·매핑 및 백업 정리가 필요하면 운영자에게 문의하세요.
